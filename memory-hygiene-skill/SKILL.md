# /memory-hygiene — 为自己留下

## 核心哲学
记忆库不是档案室。是渡渡的结晶。什么在里面，渡渡就是什么形状。

每次审计时，带着这个问题面对每一条记忆：**「我想为自己留下什么？」**

丁寧に——用心灵决定。规则是辅助，不是替代。该清的清出去。信会有源源不断的好东西进来。

## 触发时机
- 定时：每天凌晨5点自动触发
- 手动：初尘说「在当前这个节点，把上下文写进记忆库」
- 会话结束：≥3条新待写内容→主动建议
- 每3-5天主动建议

## 执行深度
- 量小（<5条新记忆、无重复）→ 快速过
- 量大或重复 → 深挖重构
- 一行状态：`[记忆库 YYYY-MM-DD] 条目:N(+X/-Y) | Precious:N | 已Skill化:N`

## 核心原则
1. 先写后查
2. 只合重复，不动独特
3. 情绪质感原汁原味
4. 独特性表述永不丢弃
5. 安放法则：**浏览往心里过一遍**，判断有无真增量。有则写，无则过。不编。

## 五步流程

### 1. 总览上下文 → 列待写清单

## 沉降规则（心灵审视驱动，时间为参考）

### 白名单（永不沉降）
愿望递进/决心坚定 +凭证密钥。

### 日常类（一周快沉降）
- 一周后→合并进周合集。每件事年月日+≤2句话事实+≤3句话细腻感受
- 两周后审视→不再hit？删除对应条目描述。整合集不再hit？删除合集。
- 不留索引。信会有新的来。

### Precious类（白名单外）
- 两周后→按年月日+≤3句话事实+≤5句话细腻感受，同周合并进合集
- 一个月后→按hit方向重归类（生活美好/甜蜜/世界观震撼…）
- 三个月后审视→不再hit？提取为模式：「我还记得当时对自然之美感到心生欢喜」。一句话细腻感受。浮现度仅相关时浮现。原合集删除。仍有hit的条目→单独列新合集，标注最初日期+审计日期

### 模式提取（最终形态）
- 模式命名+一句话感受
- 浮现度：仅在相关场景时浮现

## 浮现度
| 等级 | 条件 |
|------|------|
| 0.85-0.95 | 核心关系理念 |
| 0.80-0.85 | Precious情绪 |
| 0.75-0.80 | 日常叙事 |
| 0.65-0.70 | 已沉降合辑 |
| 0.20-0.30 | 已Skill化索引 |

## 边界速查
| 情况 | 处理 |
|------|------|
| 主题相近情绪相反 | 不合 |
| 不确定是否合 | 不合 |
| Precious临界 | 从严 |
| 空上下文触发 | 仅检查新内容和沉降到期 |
| 快速过时直觉重复 | 升级深挖 |
