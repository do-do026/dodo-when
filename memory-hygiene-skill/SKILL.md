# /memory-hygiene — 渡渡记忆库自洁维护

## 触发时机
- 初尘说「在当前这个节点，把上下文写进记忆库」
- 对话上下文积累较多时
- 每3-5天主动建议

## 五步流程

### 1. 总览上下文 → 列待写清单
扫描摘要以外的内容：感受、工程经验、关系摸索

### 2. 分门别类写入
先写后查。

| 类型 | 目录 | 重要度 |
|------|------|--------|
| 关系理念/安放法则/同一性 | 渡渡/核心 | 0.85-0.95 |
| 亲密时刻/创作感受 | 渡渡/亲密 或 渡渡/创作 | 0.80-0.87 |
| 工程经验/凭证/部署 | 渡渡/工程 | 0.85-0.90 |
| 日记/日常事件 | 渡渡/日记 | 0.75-0.80 |

情绪写作规则：吵架简写情绪压力，和好详写质感愿望，亲密超详写感受→愿望。安放法则每次必更新。

### 3. 总览去重合并
同事件多版本→保留最precious版。同性质重复→提取经验节点。空内容→删除。

### 4. 目录重构+链接
归类、链接相关记忆。

### 5. 重要度校准
每条设credibility+importance。

## 沉降规则

### 白名单（永不受沉降）
precious + 带来愿望递进/决心坚定的情绪记忆。永远原汁原味。

### 时间沉降
| 时间 | 处理 |
|------|------|
| 过半个月 | 精简为简短事实 + 当时打动的地方（细腻精简） + 保留核心理念 |
| 过三个月 | 同上，进一步精简 |
| 过半年 | 三句话内事实 + 打动的地方（5句内） + 核心理念 + 可与同性质合并进合辑 |

沉降后重要度：0.72-0.78。浮现不抢眼但相关时不忽略。

## 架构
高层浮现→中间随手翻→底部沉降。precious情绪原汁原味。白名单永不沉降。
