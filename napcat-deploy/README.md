# napcat-deploy

QQ+NapCat 远程服务器部署与故障排除技能包。

## 安装

将本目录放入 Operit 的 skills 目录：
```
/sdcard/Download/Operit/skills/napcat-deploy/
```

或通过 Operit 插件市场安装。

## 触发

当对话中出现以下关键词时自动激活：
- 部署NapCat / QQ机器人部署
- NapCat二维码过期 / 登录
- NapCat启动失败 / 依赖缺失
